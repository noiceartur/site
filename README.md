# 🥥 CocoPuro — Site de Venda de Coco (React + Vite)

Site profissional para venda de coco verde.

## 🚀 Como rodar

```bash
cd cocopuro-vite
npm install
npm run dev
```

## 🖼️ Imagem

Coloque sua imagem `image.png` na pasta `public/`.

## 📝 Para editar

Abra a pasta no VS Code e edite os componentes em `src/components/`.
